# Интернет магазин «Professional Shop»
Второй проект. Многостраничный сайт (5 стр) Интернет-магазина одежды с адаптивным дизайном, каталогом, корзиной, карточкой товара и формой регистрации на чистом
HTML5/SASS с семантической версткой.


## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


## 🎯 Ключевые функции

### UI/UX элементы
- Адаптивное бургер-меню для мобильных устройств
- Фильтр товаров в каталоге (HTML/CSS) через details
- Сортировка по размеру с кастомными чекбоксами
- Корзина с формой доставки и расчетом суммы
- Форма регистрации с валидацией пароля
- Карточки товаров с hover-эффектами (кнопка Add to Cart)
- Пагинация в каталоге

## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки верстки многостраничного интернет-магазина с адаптивом, анимациями и формами, готового к интеграции с бекендом.**
